# itsnotasandwich.shop

Static site for it's not a sandwich, Munich.

- `index.html`: homepage hero in the new typography
- `css/typography.css`: site-wide type (Gelasio serif, JetBrains Mono labels, cream / ink / mustard)
- `fonts/`: self-hosted webfonts (SIL Open Font License)
- `merch/paper-and-cups.html`: deli paper and cup mockups in the same type
- `previews/`: rendered screenshots
